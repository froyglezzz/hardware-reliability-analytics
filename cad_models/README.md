# CAD Models

This directory stores parametric CAD models for HPC package geometries.

## Expected Deliverables

| File | Tool | Description |
|------|------|-------------|
| `power10_mcm_package.x_t` | SolidWorks 2024 | POWER10 Multi-Chip Module outer envelope |
| `c4_bump_array.x_t` | SolidWorks 2024 | C4 solder bump array (150 µm pitch) |
| `thermal_interface_material.stp` | Ansys SpaceClaim | TIM layer geometry for FEA import |

Models are exported in Parasolid (`.x_t`) and STEP (`.stp`) for interoperability
with Ansys Mechanical and HyperMesh.
